💡 核心設計原則

1️⃣ 多 API Key 自動輪替

  • 6 個 Keys × 15 RPM = 90 RPM
  • 0.8 秒/張圖片 (vs. 4 秒)
  • 無縫切換失效 Key

2️⃣ 智能分段處理

  • < 100KB：直接處理
  • ≥ 100KB：自動分段
  • 智能邊界檢測

3️⃣ 三檔位筆記系統

  • 超詳細版 (20K 字)
  • 標準版 (10K 字)
  • 精簡版 (5K 字)

4️⃣ Thinking Mode 深思考

  • Gemini 2.5 Pro 推理
  • 8 個角色分析
  • 品質 +25%

5️⃣ 統一配置與重試

  • 集中式配置管理
  • Exponential backoff
  • 最多 3 次重試
